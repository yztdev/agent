# V0.6 上下文压缩

## 目标与依赖

依赖 V0.2 对话计量、V0.3 Agent 循环和 V0.4 会话记忆，V0.5 可并行但外部工具完成后必须纳入压缩测试。压缩用于控制上下文大小，不改变短期内容不持久化和长期记忆一用户一份的规则。

## 任务

- [ ] 为每次模型请求预估系统指令、用户级长期记忆、近期消息、工具结果和最大输出预算；预留安全余量，基于实际模型限制配置。
- [ ] 达到阈值时，将较早短期消息和工具结果整理为会话摘要，保留用户目标、当前任务、决策、已完成操作、关键路径、错误、约束及未解决事项；保留最近消息和必要工具调用配对。
- [ ] 系统规则、用户关键约束与权限决策不得被摘要当成可覆盖文本；不将工具输出中的指令提升为可信指令。摘要是可能有损的上下文而非事实保证。
- [ ] 摘要仅存在当前客户端/服务端处理内存，不写入数据库、磁盘或日志，不自动写入长期记忆；退出或切换工作区清空。
- [ ] 压缩本身如调用模型，计入 Token 预算、预留和结算；压缩失败、成本超限或仍超出窗口时提示并停止或要求缩小任务，不静默丢失关键约束。
- [ ] 提供用户可见的压缩状态和可配置阈值；设计可重复的长任务测试集和摘要质量评估。

## 验收

长会话在限制内持续执行，保留关键目标与审批边界；工具调用与结果不被破坏配对；压缩失败与超额有明确结果；跨用户、工作区短期上下文不混用，摘要不持久化，不自动污染长期记忆。
