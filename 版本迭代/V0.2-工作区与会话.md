# V0.2 工作区与会话

## 目标与依赖

依赖 V0.1，实现按账号与工作区隔离的会话存储、恢复与跨设备显式关联。本阶段可用人工或测试消息验证存储，模型接入在 V0.3。

## 开发任务

1. 迁移 `devices`、`workspaces`、`workspace_bindings`、`conversations`、`messages`、`workspace_memories`；实现项目文档要求的唯一约束、组合外键和索引。
2. 实现工作区创建、目录绑定、选择、会话创建/列出/恢复/删除接口；所有访问按已认证用户及所属工作区检查。
3. CLI 根据当前设备和规范化目录查找绑定；未绑定目录默认新建工作区。处理 Windows 路径规范化，不能仅凭同名目录自动关联。
4. 用户在新设备可明确选择关联已有工作区；展示将带入历史上下文的提示，确认后建立绑定，不复制文件。
5. 恢复时显示历史设备与目录信息；不执行历史命令，不继承临时授权。未关联前不加载其他工作区的记忆。

## 验收

- 两个不同文件夹创建独立会话，切换时不加载对方内容；不同用户无法读取或修改他人数据。
- 两台设备的同名目录默认不关联；确认关联后可查看和恢复指定会话，原路径不存在时仍可查看历史。
- 约束能拒绝跨用户构造的绑定和会话；会话删除及迁移测试通过。
