# V0.1 基础架构与账号

## 目标与依赖

建立 Java 客户端、服务端和 PostgreSQL 基础，用户可以通过用户名和密码登录。无前置版本；固定 Java LTS、构建工具、服务端框架及 PostgreSQL 版本，并记录版本选择。

## 开发任务

1. 建立 client、server、shared 模块、构建及配置管理；编写 Windows 本地启动说明。
2. 建立 PostgreSQL 迁移机制，创建 `users`、`auth_sessions`；定义备份恢复和本地测试数据库使用方式。
3. 实现受控的管理员创建账号流程、唯一用户名校验、带独立盐值的密码哈希及登录限流；不记录明文密码。
4. 提供登录、当前用户、退出接口；凭据可过期和撤销，接口使用 HTTPS。CLI 密码输入不回显，安全存储不可用时只保持进程内登录。
5. 增加配置校验、日志脱敏及基础错误处理；准备 CI 构建和自动化测试。

## 验收

- Windows 可按说明启动并登录；错误密码不能登录，退出后的凭据不能访问受保护接口。
- 唯一用户名冲突、令牌过期和账号禁用有明确处理；日志和数据库不出现明文密码或令牌。
- 数据库可从空库执行迁移，认证与限流测试通过。此版本不提供模型对话或工作区记忆。
