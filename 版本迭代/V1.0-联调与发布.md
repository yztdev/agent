# V1.0 联调与发布

## 目标与依赖

依赖 V0.1～V0.4。完成主项目文档的全部 P0 功能和验收，提供可部署、可安装、可恢复的首个版本。

## 开发任务

1. 联调账号、工作区、会话、模型、配额及工具，检查每次模型调用均受配额控制，所有权限均由当前客户端执行。
2. 验证管理后台的权限、用户筛选、用量明细、额度调整及审计；测试双设备显式工作区关联、不同账号和目录隔离、会话删除、认证撤销、服务端故障恢复及 Token 待核对流程。
3. 在 Windows 验证安装、编码、路径、子进程、文件冲突与审批体验；覆盖实际开发任务和只读运维诊断。
4. 编写服务端 PostgreSQL 部署、HTTPS、账号创建、配置、备份恢复、升级迁移和客户端使用说明；说明敏感数据保留及删除策略。
5. 执行主项目文档验收，整理已知限制与测试结果；未通过的 P0 项不得标记完成。

## 发布验收

- 主项目文档全部 P0 验收项通过，至少完成一次双终端跨设备恢复及一项真实代码修改验证任务。
- 数据库从空库安装和从备份恢复均经演练；权限隔离、配额并发和未知用量恢复有测试记录。
- 安装及部署文档可由新用户独立操作，模型费用与用量、无系统沙箱等限制清楚可见。
