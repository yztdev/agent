# V1.0 集成与发布

## 目标

依赖 V0.1～V0.7，完成 MCP 工具接入后，交付 Windows 客户端和 Linux 服务端的首版。若 MCP 关键验收失败，不标记完整 V1.0。

## 任务与验收

- [ ] Windows 客户端连接 Linux 服务端，验证用户身份、工作区、用户级长期记忆、内存短期会话和管理员后台。
- [ ] 在实际示例项目分别执行 ReAct 和 Plan-and-Execute；验证内置及MCP 工具、审批、冲突、失败与重规划。
- [ ] 用长任务覆盖上下文压缩及安全约束保留；全部模型调用（对话、工具循环、摘要和规划）计入用户配额。
- [ ] 验证越权、提示注入、敏感数据、超时、进程中断和重复请求；短期消息、摘要及计划不写入数据库、持久化文件或日志。
- [ ] 验证 PostgreSQL 迁移、备份恢复、认证与证书部署；发布部署、安装和升级文档，明确证书轮换与用户记忆删除策略。
- [ ] 记录实测系统、模型版本和证据；公开未解决限制，不将未验证功能或系统级沙箱当作已实现。
