# V0.4 Agent 工具与审批

## 目标与依赖

依赖 V0.1～V0.3，打通服务端 Agent 循环与客户端本机工具，实现可审查的开发及本机运维任务。

## 开发任务

1. 定义带任务 ID、工具调用 ID、参数、结果及状态的客户端/服务端协议；服务端组织模型循环，客户端独立校验参数及权限。
2. 实现目录列举、文件读取和文本搜索，限制工作区路径、符号链接、敏感文件与输出大小；首版支持 Windows。
3. 实现文件暂存、diff、接受/拒绝、原文件哈希冲突检查及写入结果报告；覆盖创建、修改、删除、重命名和部分失败。
4. 实现受限只读命令识别：仅可可靠验证的命令直接执行；未知、重定向、脚本及可能修改状态的命令须明确审批。处理超时、中断及进程清理。
5. 实现循环次数和输出限制、失败处理、用户取消及最终报告；每次模型调用沿用 V0.3 的预留和结算。

## 验收

- 在示例仓库定位代码、生成修改、预览并接受后运行经授权的验证命令；结果说明修改和测试情况。
- 拒绝文件或命令审批后操作不发生；文件预览后被外部更改时不覆盖；跨边界路径及敏感文件按策略处理。
- 未知命令不能被错误当作只读放行；超时和中断后界面恢复并报告状态。Windows 完成基本工具测试。

## 阶段限制

首版无操作系统级沙箱；命令执行可能影响文件、网络或系统状态，必须在审批中说明已知与未知影响。

## 可执行任务清单

### 协议与运行时

- [ ] 定义任务和工具调用的唯一标识、参数 schema、结果、错误、超时和取消状态；校验调用归属与当前连接。
- [ ] 服务端实现工具调用循环、模型预算及循环上限；断线或重连不得自动重放可能产生副作用的工具调用。
- [ ] 客户端对每次请求独立校验参数、路径及审批，服务端文本或历史记录不能代替本机批准。

### 文件工具

- [ ] 实现受限列表、读取和搜索，包含忽略规则、输出截断、敏感文件保护与路径/符号链接检查。
- [ ] 实现独立暂存、diff、逐次接受与拒绝；对新建、删除和重命名分别定义预览与原始状态检查。
- [ ] 接受时重新校验目标状态，外部变更则中止；多文件部分写入失败时列明实际成功和失败项。

### 命令与反馈

- [ ] 按 Windows 定义最小可验证只读规则；未知程序、管道、重定向、脚本及不明确参数默认审批。
- [ ] 执行前展示完整命令、工作目录和已知影响；实现拒绝、超时、取消、输出限制及尽力清理子进程。
- [ ] 实现 `/diff`、任务进度和结果报告，说明实际修改、验证命令、失败及尚未完成事项。

### 交付检查

- [ ] 自动测试越界、链接、敏感文件、审批拒绝、冲突、部分失败、未知命令与重复调用。
- [ ] 在 Windows 示例仓库完成代码定位、预览修改、批准写入与验证；另验证只读运维诊断。
