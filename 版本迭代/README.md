# 版本迭代总览

本目录将项目文档的 P0 拆成可验证的内部版本。依赖依次为 V0.1 → V0.2 → V0.3 → V0.4 → V1.0；V0.x 是阶段性交付，不代表已经满足完整首版。实际工作量与日期在团队规模和技术验证后估算。

| 版本 | 目标 | 阶段完成标志 |
| --- | --- | --- |
| [V0.1](V0.1-基础架构与账号.md) | 工程、PostgreSQL 与登录 | 能创建账号并从 CLI 登录、退出 |
| [V0.2](V0.2-工作区与会话.md) | 工作区隔离与跨终端恢复 | 不同目录记忆隔离，同账号可显式跨设备关联 |
| [V0.3](V0.3-模型与Token配额.md) | DeepSeek 对话与配额 | 对话可计量，配额和并发结算可靠，管理员可观测用户用量 |
| [V0.4](V0.4-Agent工具与审批.md) | 本机工具、Agent 与审批 | 完成读取、预览修改、受控命令的任务闭环 |
| [V1.0](V1.0-联调与发布.md) | 完整验证与交付 | 满足主项目文档全部 P0 验收标准 |

共同约束：每版均维护数据库迁移、必要的自动化测试及运行说明；权限边界由客户端执行，服务端负责认证、账号与工作区隔离。不得把阶段性占位功能描述为已完成。

## 执行约定

每个版本先完成前置版本验收，再按文档中的可执行任务清单开发。每项完成时记录代码位置、测试结果及未解决问题；版本验收以对应文档和主项目文档为准。模型能力、版本选型及工期以实际验证和资源为准，不预设已完成。
