# 项目版本迭代总览

> 本计划为需求设计，不表示相应功能已经实现。依次推进 V0.1 → V0.2 → V0.3 → V0.4 → V0.5 → V0.6 → V0.7 → V1.0；阶段验收通过再进入下一阶段。工期待技术验证与资源确定后估算。

| 版本 | 目标 | 完成标志 |
| --- | --- | --- |
| [V0.1](V0.1-基础架构与账号.md) | 登录、HTTPS、PostgreSQL、Windows CLI | 基本登录已实现；部署与安全持续改进 |
| [V0.2](V0.2-模型与Token配额.md) | DeepSeek、对话、Token 配额与后台 | 单轮提问及每次模型调用计量可验证 |
| [V0.3](V0.3-ReAct工具与审批.md) | 自研 ReAct 与内置工具 | 单个任务内的模型—工具—结果循环及本机审批闭环 |
| [V0.4](V0.4-工作区与记忆.md) | 用户级长期记忆、窗口内短期会话 | 同用户共用一份长期记忆，跨轮消息仅存内存 |
| [V0.5](V0.5-外部工具接入.md) | MCP 外部工具接入 | 完成 MCP 适配、审批、隔离与端到端测试 |
| [V0.6](V0.6-上下文压缩.md) | 上下文预算与压缩 | 长任务可压缩，保留关键约束，不持久化短期内容 |
| [V0.7](V0.7-Plan-and-Execute.md) | 自研规划与执行模式 | 计划可审阅，按步骤执行、失败可处理 |
| [V1.0](V1.0-联调与发布.md) | 集成、部署与完整验收 | 全链路及安全、数据隔离、平台验证通过 |

外部工具使用 MCP 协议；具体 SDK、协议版本和首版传输方式在 V0.5 技术设计时确定并验证。

共同约束：Java 自研编排；Windows 客户端执行本机工具及审批，Linux 服务端负责模型、配额和用户级长期记忆。用户每人一份长期记忆，同账号跨工作区共用；短期会话跨当前会话的多轮提问保留，短期消息、压缩摘要和计划仅存于进程内存，不写入数据库、持久化文件或日志。每版维护迁移、测试和运行说明。
