# V0.3 DeepSeek 对话与 Token 配额

## 目标与依赖

依赖 V0.1、V0.2。服务端对接 DeepSeek，CLI 提供流式多轮对话；每次模型调用受用户配额约束。

## 开发任务

1. 迁移 `token_accounts`、`token_requests`、`token_adjustments`；建立约束、状态和审计记录。管理员可创建和调整累计额度。
2. 对接 DeepSeek 的流式调用及实际用量返回；服务端注入 API 密钥，客户端不接触密钥。先验证模型上下文、工具调用、流式用量和失败行为，保留真实接口测试记录。
3. 实现输入预算估算、最大输出上限、原子预留与幂等结算；若无法可靠确定输入上界则拒绝请求并说明，避免假定估算一定精确。
4. 按调用唯一 ID 保存状态；失败或中断且用量未知时保留预留、标记待核对；提供管理员核对处理。对已发送但结果不明的调用不盲目重试。
5. 实现管理员后台及受保护的管理 API：用户列表筛选分页、额度及用量、请求明细、待核对状态和配额调整审计；后台默认不展示对话内容。
6. CLI 显示总额度、已用、预留和可用剩余量；余额不足禁止新模型请求，但历史会话仍可访问。

## 验收

- 模拟和真实接口联调均可完成多轮流式对话，输入和输出用量被正确累计；模型密钥不出现在客户端、日志或消息中。
- 管理员能查看用户用量与调用明细、调整额度并查看审计；普通账号不能访问后台 API。
- 同一账号并发请求不能重复预留，重复结算和服务重启不重复扣量；未知用量保持待核对且可处理。
- 两个账号额度隔离，同一账号两个终端显示一致的服务端余额；额度不足时不调用模型。

## 阶段限制

此版只提供对话和会话恢复，不执行本机工具。实际 Token 估算及未知用量核对能否由供应商接口支持须在联调中验证，不能将未确认能力作为上线前提已满足。

## 可执行任务清单

### 模型能力验证

- [ ] 核实所选 DeepSeek 模型的上下文限制、工具调用、流式用量及中断行为；记录实际结果、接口版本和无法保证的场景。
- [ ] 实现服务端模型适配器、超时与可取消的流式传输；错误及中断向客户端返回明确状态，不暴露密钥。
- [ ] 按账号与工作区加载消息，保存用户消息和模型输出；明确流中断时部分回复的状态。

### 配额与结算

- [ ] 创建账户、调用记录、额度调整迁移；定义状态转换及请求唯一键，编写额度调整服务。
- [ ] 实现单次调用输入上界与最大输出预算，短事务原子预留；估算依据不可靠或额度不足时禁止发出请求。
- [ ] 收到可信用量后事务内幂等结算；未发出或可证明无用量时释放预留，结果未知时转待核对，不盲目重试。
- [ ] 提供管理员核对未知用量的流程与审计，说明供应商无法提供逐请求核对数据时如何人工处理；超出预留时记录实际差额并阻止后续请求。
- [ ] CLI 查询并展示额度、已结算、预留和可用余额；每次模型调用独立计量，包含后续工具调用循环。

### 管理后台

- [ ] 实现管理员授权与受控初始化；用户列表支持筛选、分页和排序，展示账户额度、用量、预留及待核对数。
- [ ] 实现用户调用详情和时间、状态筛选；说明统计时间口径，不展示对话及敏感凭据。
- [ ] 实现配额调整确认、原因输入及调整历史；账户更新与审计同事务提交。

### 交付检查

- [ ] 以受控模型响应覆盖并发预留、重复结算、超时、取消、服务重启和用量缺失；保留真实 API 联调结果。
- [ ] 验证管理员与普通用户权限、后台筛选统计及审计，输出部署和待核对操作说明。
