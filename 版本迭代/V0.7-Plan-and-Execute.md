# V0.7 Plan-and-Execute 模式

## 目标与依赖

依赖 V0.3 自研 ReAct 和 V0.6 上下文压缩；与 V0.5 外部适配共用工具和权限接口，若 MCP 接入尚未完成，本版先只支持已实现工具。模式按任务选择：普通任务用 ReAct，复杂任务可选择规划执行；模式切换和是否自动判断由配置决定，用户可显式选择。

## 任务

- [ ] 实现结构化计划：目标、步骤、依赖、状态、预期验证；不将模型内部推理作为用户可见记录或持久化数据。
- [ ] 展示计划并允许用户修改、取消；计划展示本身不授权后续工具，写文件和命令仍逐次按既有策略审批。
- [ ] 自研计划执行器按依赖顺序调用 ReAct 完成每步，记录内存状态与证据；每步结束核验完成条件，失败时停止、重试或重规划并向用户说明。
- [ ] 重规划保留用户目标、已执行操作和未完成事项，避免重放已批准执行但结果不明的有副作用操作；超出预算或权限时停止。
- [ ] 计划和执行状态仅保存在内存；用户退出或进程结束不恢复，不保存到长期记忆或数据库。规划、执行、验证、重规划和压缩调用全部纳入 Token 配额。
- [ ] 提供模式切换、执行进度、取消与完成报告；设计正常、部分失败、审批拒绝、超时和重规划测试。

## 验收

多步任务能呈现计划、逐步执行和验证，步骤失败及拒绝后不假报成功；计划不授予工具权限，不重试状态不明的副作用；上下文压缩不破坏步骤依赖；重启后短期计划不可恢复。
